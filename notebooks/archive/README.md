# Archived notebooks

Development notebooks kept for reference. **Not maintained:** paths are machine-specific
(`D:\...`), some cells use APIs that have since changed, and outputs are cleared. The checks
they performed are now covered by the test suite (see `docs/testing.md`).

| Notebook | What it was for |
|----------|-----------------|
| `testing_forces.ipynb` | EFD vs TOLEOS/POD comparisons and GMAT vs Orekit SRP checks |
| `testing_swarm.ipynb` | SWARM-B validation (external data and the `data_io` package) |
| `testing_champ.ipynb` | CHAMP vs TOLEOS. **Cell 10 generated the bundled `contigo/data/CHAMP_POD_20050816_20050822.hdf`**; keep it as the provenance of that file |

Maintained notebooks are in `notebooks/tutorials/` (with Colab badges) and
`notebooks/analysis/`.

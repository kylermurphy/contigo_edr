# Testing

How the CONTIGO test suite is organised, what each test checks, and how to add tests.

## Running the tests

```bash
pytest                         # fast tier: no network, no Java (what CI runs)
pytest tests/test_coords.py -v # one file
pytest --run-network           # also tests that need internet (NAIF, ICGEM, GitLab)
pytest --run-orekit            # also tests that start the Orekit JVM
pytest --run-slow              # also long-running tests
pytest --run-all               # everything
```

The fast tier takes about 10 seconds. CI runs it on Python 3.10, 3.12, 3.13 and 3.14 against a
non-editable install, with `CONTIGO_OFFLINE=1`, after `ruff` and `black --check`.

## Tiers and markers

| Marker | Use it when the test... | Runs with |
|--------|-------------------------|-----------|
| (none) | needs neither network nor Java, and takes under ~10 s | always |
| `@pytest.mark.network` | downloads something | `--run-network` |
| `@pytest.mark.orekit` | starts the JVM | `--run-orekit` |
| `@pytest.mark.slow` | takes over ~10 s | `--run-slow` |

The fast tier is enforced: an unmarked test that calls `utils.dl_file` or `utils.wf_mtime`
fails with "network access in a fast-tier test". Note that on a fresh machine the Orekit tier
also needs the network once, to download the Orekit data (see `docs/ToDo.md`).

## Shared fixtures (`tests/conftest.py`, `tests/_support.py`)

| Fixture or helper | What it gives you |
|-------------------|-------------------|
| (session, automatic) | a temporary `CONTIGO_CACHE_DIR`, so tests never touch your real cache; the bundled SPICE kernels loaded; `config.state` restored after each test |
| `circular_orbit` / `make_circular_orbit` | an exact circular Keplerian orbit, rotated into ECEF. Its Jacobi integral is conserved, so its EDR is zero |
| `sc_single`, `sc_multi` | `Spacecraft` built from arrays; `sc_multi` has 3 IDs with shuffled times |
| `constellation_fixture` | `Constellation(sc_multi)` |
| `fake_provider` / `FakeProvider` | an ephemeris provider that counts its calls |
| `FakePotential`, `FakeForce` | a point-mass potential `GM/r` and a force `a = -k v` with known EDR |
| `esa_pod_small`, `orekit_ref_small`, `esa_constellation` | about two orbits of `data/ESA_pod.hdf` and Orekit's results for them (`tests/data/*.csv.gz`, regenerated by `tests/data/make_fixtures.py`), so CONTIGO-vs-Orekit comparisons run without Java |
| `multi_sc`, `constellation` (`tests/plotting/conftest.py`) | small synthetic data for plot tests |

## Conventions

- **Say where the expected number comes from** in the docstring: an analytic formula, a
  definition (WGS-84), an independent tool (Orekit), or a stored snapshot.
- Test docstrings start with a row ID from the catalogue below (for example `SC-07:`). New
  test groups get a new prefix.
- Prefer exact or analytic expectations on small synthetic data over large files.
- A known bug can be pinned with `pytest.mark.xfail(strict=True, raises=<ExactError>)`. The
  test then fails once the bug is fixed, which forces removal of the marker.
- Plot tests check the numbers going into the plot; a figure that "looks right" is not a test.

## Test catalogue

### Spacecraft and Constellation (`test_spacecraft.py`, `test_constellation.py`)

| ID | Checks |
|----|--------|
| SC-01 | load from arrays: `N`, shapes, default ID `"NO_ID"` |
| SC-02 | `unit_input='km'` converts to SI and does not change the caller's array |
| SC-03 | bad input raises `ValueError` (missing or bad time scale, wrong shapes) |
| SC-04, SC-04b | properties broadcast to `(N,)`; property columns read from files; an explicit value overrides a column |
| SC-05, SC-06 | CSV/HDF loaders (globs, zipped files, ID from file name) and their errors |
| SC-07 | `split_by_id`: one object per ID, sorted by GPS time, properties sliced consistently |
| SC-08, SC-09 | time axes: ET - GPS = 51.184 s; leap seconds (13 s in 2005, 18 s in 2017) |
| SC-10 | `spherical()` on known points |
| SC-11, SC-11b | SP3 loader (units, epochs, multi-satellite); duplicate (ID, time) rows from overlapping files are dropped when IDs are real |
| SC-12 | `state_data` cache and time axes are refreshed after a reload |
| CO-01 to CO-04 | building from kwargs, a multi-ID `Spacecraft` or a list; `+`/`+=` keep the time axes aligned; container protocol |

### EDR and EFD (`test_edr_efd.py`)

| ID | Checks |
|----|--------|
| ED-01 | circular orbit, point-mass potential, no forces: EDR stays at zero (Jacobi integral) |
| ED-02 | `a = -k v`: `EDR(t) = k |v|² t` (sign convention and integration) |
| ED-03 | one `(B, N, 3)` force equals B separate `(N, 3)` forces |
| ED-04 | `compute_denom` = `b |v|³ t` for constant `b` and speed |
| ED-05 | `compute_den`: window count, midpoint times, `efd = -2k / (b |v|)`, full window span |
| ED-06 | the constructor warms the ephemeris cache in one provider call |
| ED-07 | regression snapshot `tests/data/edr_snapshot.npz` (regenerate with `make_edr_snapshot.py` only for an intended change) |
| ED-08 | (orekit) full ESA orbit vs Orekit's EDR, loose tolerance for now |
| ED-09 | `compute_denom` vs Orekit's stored denominator |

### Coordinates and Earth orientation (`test_coords.py`, `test_earth_orientation.py`)

| ID | Checks |
|----|--------|
| CD-01 to CD-05 | geodetic conversion: points on the ellipsoid, round trip to 40,000 km, shapes, speed |
| FX-01 to FX-05 | inertial transform: equatorial surface speed `omega a`, round trip, positions vs states, input errors, Orekit's inertial states within 1 m |

| EO-01 to EO-08 | bundled coverage; no network for covered dates; one update attempt per session; a failed update leaves the cached kernel usable |
